# BearObs Golden Vault

This fixture is synthetic. It contains no copied or transformed user Vault content.

`contract.json` is the executable M0-05 boundary for future Markdown parser tests:

1. Load each file below `vault/` as raw bytes.
2. Parse without modifying those bytes.
3. Compare parser output with the matching `parserCases[].expected` object.
4. Treat omitted expectation fields as out of scope, not as empty parser output.
5. Keep stable case identifiers; add a new case instead of changing unrelated semantics.

The checked-in syntax notes are deliberately small and inspectable. Mechanical fixtures are generated by:

```bash
xcrun swift \
  -module-cache-path .build/SwiftModuleCache \
  scripts/fixtures/generate-golden-vault-assets.swift
```

The generated corpus contains one exact 1 MiB Markdown note, 256 small notes, a UTF-8 BOM
note, and a CRLF note. `make check` validates the contract, paths, byte profiles, and corpus
sizes.
