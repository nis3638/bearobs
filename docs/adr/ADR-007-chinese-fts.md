# ADR-007：中文 FTS 初始策略

- 状态：Accepted
- 日期：2026-08-01

## 上下文

GRDB/FTS5 Spike 已验证 `unicode61`、迁移、事务和性能，但没有足够的真实中文 Vault 语料证明
分词召回率。现在引入分词扩展只会把猜测固化为依赖。

## 决策

- M1 初始使用 FTS5 `unicode61`，锁定已验证的 GRDB 版本和 migration 方式。
- 使用授权或合成中文 Vault 测量召回率、误匹配、索引体积和查询延迟，再决定是否引入额外分词器。

## 不做什么

不因少量样例宣称中文搜索已经解决；不在 M0 提前引入 ICU、第三方中文分词或服务端搜索。

## 复审条件

M1 完成真实中文语料基线后复审。若关键查询的召回率或延迟不能满足产品场景，再以独立 ADR 比较
分词方案、iOS 体积、迁移成本和向后兼容性。
