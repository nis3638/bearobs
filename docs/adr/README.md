# Architecture Decision Records

这些 ADR 只冻结已验证的架构决策。`Accepted` 表示当前实现和计划必须遵守；`Proposed` 表示存在
明确候选，但尚缺少外部授权或验证证据，不能据此宣称能力已经可用。

| ADR | 状态 | 主题 |
|---|---|---|
| ADR-001 | Accepted | Vault 内容事实源与本地工作副本 |
| ADR-002 | Accepted | 路径作为 MVP 文件身份 |
| ADR-003 | Accepted | 索引、同步账本与用户状态物理隔离 |
| ADR-004 | Accepted | 三方同步与无静默覆盖 |
| ADR-005 | Accepted | Markdown 原文编辑 |
| ADR-006 | Proposed | 首个认证 WebDAV 服务与能力矩阵 |
| ADR-007 | Accepted | 中文 FTS 初始策略 |

ADR-006 在取得专用测试账号、可信 HTTPS 实例和认证证据前不得改为 `Accepted`。
