# ADR-003：索引、同步账本与用户状态物理隔离

- 状态：Accepted
- 日期：2026-08-01

## 上下文

内容、索引、同步账本和用户偏好拥有不同的重建规则与安全边界。把它们塞进一个数据库会让恢复变成
数据丢失操作。

## 决策

- `Files/` 保存工作副本；`index.sqlite` 保存可重建索引；`sync.sqlite` 保存同步基线和 action
  ledger；用户状态单独保存；凭据只进入 Keychain。
- 冲突副本位于独立冲突目录，不参与普通缓存清理。
- 重建或删除 `index.sqlite` 不得读取后修改 Markdown、同步账本、用户状态或凭据。

## 不做什么

不把访问令牌、密码、完整 URL、笔记正文或任意底层错误文本放进普通配置、日志或索引。

## 后果与复审

M1 建立生产 schema 时必须保持这些物理边界；M3 账本恢复只能进入保守恢复状态，不得自动上传。
